# /legacy-bootstrap - Legacy 项目 Bootstrap

调用 `legacy-bootstrap` skill，使用 repomix 对当前本地 legacy 项目进行类型驱动的初始化认知分析。

## 使用场景

- 当前 Claude Code 或 Codex 已打开一个本地 clone 的 legacy 项目。
- 需要在需求、设计或修改代码前建立项目认知。
- 需要生成可版本化的 Cadence 项目认知文档。
- 需要让 `CLAUDE.md` 与 `AGENTS.md` 渐进式引用这些认知文档。

## 功能

执行以下流程：

1. 确认项目根目录，读取目标项目规则和入口文档。
2. 使用 `npx repomix@latest` 生成项目上下文快照。
3. **项目类型识别** — 从 repomix 输出中检测项目类型（前端/后端单体/微服务/全栈/CLI/DevOps），支持组合类型，向用户确认。
4. **确定产物清单** — 核心产物(8项) + 类型专属产物(按检测结果)，取并集。
5. **逐产物生成** — 按清单顺序逐一生成，每个产物独立完成后输出确认行。
6. **收尾验证** — 检查所有文件存在且非空，输出汇总表。
7. 更新 `CLAUDE.md` 与 `AGENTS.md` 的认知链接区域（只链接实际生成的文档）。
8. 输出 Bootstrap 汇总表和建议下一步。

## 产物覆盖

| 类别 | 数量 | 说明 |
|------|------|------|
| 核心产物 | 8 | 所有项目必选：系统总览、模块地图、数据模型、风险约束、构建测试、术语表、调研计划、总结报告 |
| 前端专属 | 4 | 组件文档、路由地图、状态管理、UI 依赖 |
| 后端单体专属 | 3 | API 端点清单、中间件链、数据访问层 |
| 微服务额外 | 2 | 服务依赖关系、基础设施拓扑 |
| CLI/工具库专属 | 2 | 命令结构、公共 API |
| DevOps 专属 | 2 | 资源拓扑、环境矩阵 |

## 模式

- **标准模式**（默认）：系统级粒度，适合中小项目
- **深度模式**（`--deep`）：模块级粒度，每个核心模块额外生成分析/风险/模型文档

## 约束

- 只处理当前打开的本地项目，不 clone 远程仓库。
- 不生成 `.ai/`。
- **逐产物生成，禁止合并多个产物到一个文件**。
- 不直接重构业务代码。
- 不编造未知业务事实。
- repomix `--skill-generate` 仅作为参考，默认不执行。
