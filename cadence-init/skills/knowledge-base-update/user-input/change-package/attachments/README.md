# 变更包附件说明

本目录只用于保存变更包五份强制文档的脱敏补充证据。附件不能替代任何强制文档或必填字段。

五份主文档和本目录全部文件必须在计算包幂等标识前通过敏感信息门禁；发现敏感内容，或无法确认附件可安全检查且已经脱敏时停止，不得对该包计算或保存内容哈希。

允许放置：

- 脱敏后的 DDL 差异。
- 数据库迁移说明或回滚说明。
- 不含配置值的配置差异摘要。
- Merge Request 导出说明或评审结论摘要。
- 脱敏后的测试与发布验证记录。

禁止放置：

- 密码、Token、AccessKey、Secret、密钥或私钥等明文凭证。
- 完整生产配置、完整连接串或未脱敏的内部地址。
- 从配置中心或生产环境直接导出的原始敏感文件。
- 敏感值哈希、确定性摘要或其他可关联衍生物。

如附件包含敏感配置键，只能保留键名、变更类型和用途，值固定写为 `<redacted>`，不得保留实际值。
