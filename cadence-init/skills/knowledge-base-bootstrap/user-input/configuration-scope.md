## 敏感信息说明

- 只记录敏感配置键、用途和值类型，不复制实际值。
- 快照指纹算法固定为：对纳入范围内文件按相对路径排序，为每个文件计算 SHA-256，再对 `相对路径 + 制表符 + 文件 SHA-256` 的有序清单计算最终 SHA-256。
- Manifest 只保存最终快照指纹，不保存单个敏感配置值的哈希。
- 重复文件哈希只在当前分析过程中临时使用，不写入 Manifest 或知识库文档。
