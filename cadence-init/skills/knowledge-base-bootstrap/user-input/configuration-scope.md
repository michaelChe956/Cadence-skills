## 敏感信息说明

- 只记录敏感配置键、用途和值类型，不复制实际值。
- Manifest 可以记录用户授权的本地文件系统路径；配置值中的内部端点必须脱敏，不得写入实际内部域名、IP 或 URL。
- 快照指纹算法固定为：对纳入范围内文件按相对路径排序，为每个文件计算 SHA-256，再对 `相对路径 + 制表符 + 文件 SHA-256` 的有序清单计算最终 SHA-256。
- Manifest 保存最终快照指纹、来源元数据和可审计范围摘要，包括 `scope_summary`、纳入文件数量或清单摘要、服务摘要与文件规则摘要；不保存原始快照、单文件内容哈希或敏感值哈希。
- 重复文件哈希只在当前分析过程中临时使用，不写入 Manifest 或知识库文档。
