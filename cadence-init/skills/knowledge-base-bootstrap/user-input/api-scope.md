# 对外能力清单与 API 执行范围

> 本文件登记项目的全部对外能力，是 KnowledgeBase 判定“对外能力”的权威来源。所选工程中发现但未登记在本清单中的 REST、RPC、消息、文件和任务能力默认归类为对内能力。

## 执行范围

- 模式：全量
- 指定能力：无

模式说明：

- `全量`：分析本清单中的全部对外能力，同时扫描工程范围内的对内能力。
- `指定`：只深挖“指定能力”列出的能力，以及完成调用链所需的内部依赖。
