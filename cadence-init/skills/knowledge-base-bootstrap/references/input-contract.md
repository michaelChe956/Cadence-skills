## 输入类型

| 类型 | 推荐内容 | 关键元数据 |
|------|----------|------------|
| DDL | 每个数据库独立导出文件 | 数据库类型、Schema、环境、导出时间 |
| 分库分表 | 路由键、分片算法、物理表规则 | 中间件、扩容方式、全局表 |
| 配置 | Properties、YAML、配置中心导出 | Profile、环境、命名空间、分组 |
| 中间件 | 名称、版本、场景、生产者、消费者 | Topic、Queue、Group、Key 规则 |
| API | OpenAPI、Swagger、Knife4j、Markdown | 版本、环境、对外范围、维护时间 |
| 非 HTTP 能力 | RPC、消息、文件、任务 | 协议、调用方、消费方、触发方式 |
| 页面路由 | 路由表、菜单、权限说明 | 前端应用、角色、环境、动态来源 |
| 领域知识 | 术语、缩写、业务规则 | 同义词、适用模块、来源人或资料 |
| 工程资料 | 构建、测试、部署、架构 | 工具版本、环境、适用分支 |

## 输入状态

### 已提供

存在独立资料且能够定位文件、环境和时间。

### 代码可推导

缺少独立资料，但代码、配置或 DDL 中存在直接或多个相互支持的证据。

### 用户确认缺失

用户明确表示当前无法提供。允许进入有限证据模式，不得反复阻塞询问。

### 待确认

尚未得到答复、资料环境不明或来源冲突。

## 模式判定

完整模式至少需要：

- 服务和模块边界明确
- DDL 或数据库结构来源明确
- 有效配置来源明确
- API 与路由分析范围明确
- 不存在阻断级来源冲突

不满足时，经用户确认进入有限证据模式。

## 敏感信息

分析前提醒用户移除或遮蔽：

- 密码、Token、Access Key、Secret Key
- 证书私钥
- 完整生产连接串
- 真实个人敏感数据
- 未授权公开的生产域名和内网地址

知识库只记录配置键、用途、值类型、环境和脱敏结构。

## 阻断问题

以下问题阻止完整模式完成：

- 无法确认项目或服务边界
- 无法确认 DDL 所属数据库或环境
- 输入资料包含无法安全隔离的敏感信息
- 同名服务、接口或表无法确定对应关系
- 目标知识库中存在损坏的管理标记，继续写入可能覆盖人工内容

阻断问题不妨碍输出有限证据结果，但必须记录影响和人工处理建议。
