== mysql 连接信息（容器内应用视角；宿主工具把主机名换为 127.0.0.1）==
JDBC    : jdbc:mysql://mysql:3306/appdb?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai&characterEncoding=utf8&useUnicode=true
账号    : root（密码默认 cadence123，以 stack/.env 的 MYSQL_ROOT_PASSWORD 为准）
CLI     : mysql -h mysql -P 3306 -u root -p
宿主直连: mysql -h 127.0.0.1 -P 3306 -u root -p（Navicat 等同）

    username: ${MYSQL_USERNAME:root}
    password: ${MYSQL_PASSWORD:${MYSQL_ROOT_PASSWORD:cadence123}}
