== rabbitmq 连接信息（容器内应用视角；宿主工具把主机名换为 127.0.0.1）==
AMQP    : amqp://guest:guest@rabbitmq:5672/（账密以 stack/.env 的 RABBITMQ_DEFAULT_USER/PASS 为准）
管理台  : http://127.0.0.1:15672（宿主浏览器；guest 默认仅本机可登录）
CLI     : docker exec -it cadence-rabbitmq-1 rabbitmqctl list_queues（或经 stack logs rabbitmq 排障）

# Spring Boot application-dev.yaml 片段
spring:
  rabbitmq:
    host: rabbitmq
    port: 5672
    username: ${RABBITMQ_DEFAULT_USER:guest}
    password: ${RABBITMQ_DEFAULT_PASS:guest}
