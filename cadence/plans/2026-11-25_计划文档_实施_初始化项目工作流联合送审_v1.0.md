# 初始化项目工作流联合送审实施计划

执行技能采用 `subagent-driven-development` 或 `executing-plans`。目标是使初始化及恢复的项目遵循确认过的工作流，同时能从旧规则安全升级。

**技术与约束**　Python 3、PyYAML、OpenSpec CLI、现有 Markdown 生成模板。沿用备份屏障、原子发布、项目提交开关和目标端加载方式。阶段由已安装的代理读取规则执行。审查如何分工以 `cadence-subagents-config` 为准。

**规格**　change `joint-change-plan-review` 的 `tasks.md`、三个 delta spec，以及 `cadence/designs/2026-11-25_方案设计_初始化项目工作流联合送审_v1.0.md`。完整 Design 的两项审查均通过，用户已回复“对，继续”，本任务委托实施。

## 审查重点

用户相似措辞受字段及完整文本保护。用户要求在联合审后看 Plan 时已有答复只消费一次。已通过的旧版联合包遇到内容修改时须重新送审。恢复时缺 Plan 与验收失败各回到对应产物。只委托方案的任务在交付后结束。
