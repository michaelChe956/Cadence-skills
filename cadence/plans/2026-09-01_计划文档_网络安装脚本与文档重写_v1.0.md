把以下函数加入 `install.sh`。临时 clone 成功后才 `mv -T` 到目标，保证三个镜像全部失败时目标目录既不创建也不残留半成品；`git clone` 的 URL 只能来自 `MIRRORS`，不得添加直连 URL：

```bash
clone_with_rotation() {
  if [[ -e "$REPO_DIR" || -L "$REPO_DIR" ]]; then
    fail "安装目标已存在，clone_with_rotation 不会覆盖：$REPO_DIR"
    return 1
  fi

  mkdir -p "$HOME/.agents"
  local staging_root url
  local -a attempted=()
  staging_root="$(mktemp -d "${TMPDIR:-/tmp}/cadence-skills-clone.XXXXXX")"

  for url in "${MIRRORS[@]}"; do
    attempted+=("$url")
    rm -rf -- "$staging_root/repo"
    log "尝试镜像：$url"
    if git clone "$url" "$staging_root/repo"; then
      mv -T "$staging_root/repo" "$REPO_DIR"
      rmdir "$staging_root"
      log "已从镜像安装到：$REPO_DIR"
      return 0
    fi
    warn "镜像失败：$url"
  done

  rm -rf -- "$staging_root"
  printf '[cadence][错误] 三个镜像均失败，已尝试：%s\n' "${attempted[*]}" >&2
  printf '[cadence][错误] 不使用直连 GitHub，也不提供离线安装。\n' >&2
  return 1
}
```

- [ ] **Step 4: 写入按 origin 跟踪分支更新的函数**

把以下函数加入 `install.sh`。它先尝试当前 origin URL（若当前 URL 不是三个镜像之一，则从第一个镜像开始），只有 `fetch --all` 失败才切换下一个镜像；fetch 成功后从当前分支的 `@{u}` 解析 `origin/<branch>`，再执行 `pull --ff-only`，不硬编码 `upstream` 或分支名：

```bash
update_repo() {
  local origin_url start_index=0 url tracking_ref branch
  local -a attempted=()

  origin_url="$(git -C "$REPO_DIR" remote get-url origin 2>/dev/null)" || {
    fail "仓库缺少 origin remote，无法执行 fetch --all / pull --ff-only：$REPO_DIR"
    return 1
  }

  for index in "${!MIRRORS[@]}"; do
    if [[ "$origin_url" == "${MIRRORS[$index]}" ]]; then
      start_index="$index"
      break
    fi
  done

  for offset in "${!MIRRORS[@]}"; do
    index=$(( (start_index + offset) % ${#MIRRORS[@]} ))
    url="${MIRRORS[$index]}"
    attempted+=("$url")
    log "使用镜像更新：$url"
    if git -C "$REPO_DIR" remote set-url origin "$url" && git -C "$REPO_DIR" fetch --all; then
      tracking_ref="$(git -C "$REPO_DIR" rev-parse --abbrev-ref --symbolic-full-name '@{u}' 2>/dev/null || true)"
      if [[ "$tracking_ref" != origin/* ]]; then
        fail "当前分支没有 origin 跟踪分支，无法安全执行 pull --ff-only"
        return 1
      fi
      branch="${tracking_ref#origin/}"
      if git -C "$REPO_DIR" pull --ff-only origin "$branch"; then
        log "仓库已 fast-forward 更新：origin/$branch"
        return 0
      fi
      fail "pull --ff-only 失败；请检查 origin/$branch 是否发生非 fast-forward 改写，必要时删除仓库后重新安装"
      return 1
    fi
    warn "remote 设置或 fetch --all 失败，继续轮换镜像：$url"
  done

  printf '[cadence][错误] 更新所需镜像均失败，已尝试：%s\n' "${attempted[*]}" >&2
  printf '[cadence][错误] 请检查网络；若 fast-forward 更新或远程历史被改写，请删除仓库后重新运行安装。\n' >&2
  return 1
}
```

期望：`awk '/remote (get-url|set-url)|fetch --all|pull --ff-only|@\\{u\\}/' install.sh` 只命中 `origin` 自适应逻辑；当前镜像的 remote 设置或 `fetch --all` 失败时按镜像清单轮换（从当前镜像开始并循环一次），`pull --ff-only` 因非 fast-forward 失败时立即返回非零并给出恢复指引。

- [ ] **Step 2: 定义单条软链同步与原子替换函数**

加入以下函数。目标不存在时创建父目录后建立链接；目标为普通文件、普通目录、非受管软链或坏的非受管软链时仅警告跳过；受管软链目标不同则在同一父目录创建临时名并用 `mv -T` 原子替换。临时名不能与已有条目冲突：

```bash
sync_one_link() {
  local link_path="$1" desired_target="$2" temp_link
  mkdir -p "$(dirname "$link_path")"

  if [[ ! -e "$link_path" && ! -L "$link_path" ]]; then
    ln -s -- "$desired_target" "$link_path"
    log "已创建软链：$link_path -> $desired_target"
    return 0
  fi

  if ! is_managed_link "$link_path"; then
    warn "目标已存在且不是受管软链，跳过不覆盖：$link_path"
    return 0
  fi

  if [[ "$(readlink -- "$link_path")" == "$desired_target" ]]; then
    log "软链已正确，无需修改：$link_path"
    return 0
  fi

  temp_link="${link_path}.cadence-tmp.$$.$RANDOM"
  while [[ -e "$temp_link" || -L "$temp_link" ]]; do
    temp_link="${link_path}.cadence-tmp.$$.$RANDOM"
  done
  ln -s -- "$desired_target" "$temp_link"
  mv -T -- "$temp_link" "$link_path"
  log "已原子替换受管软链：$link_path -> $desired_target"
}
```

期望：第一次同步创建链接；第二次同步对相同目标不改动 inode；将受管链接改为另一个合法目标后再次同步时，最终 `readlink` 等于新目标且目标位置没有遗留 `.cadence-tmp` 文件；普通目录内容和非受管链接目标保持不变。

- [ ] **Step 3: 定义 `sync_links()` 扫描源 skills 并同步三层**

加入以下函数。它只把含有普通文件 `SKILL.md` 的 skill 目录加入期望集合，并按“共享层 → Codex 层 → Claude 层”顺序建立链接；源目录缺失直接失败，避免成功输出掩盖仓库损坏：

```bash
sync_links() {
  local skill_file skill_dir skill_name layer_root entry entry_name
  local -a layer_roots=("$SHARED_ROOT" "$CLAUDE_ROOT" "$CODEX_ROOT")
  declare -A expected_skills=()

  [[ -d "$SOURCE_ROOT" ]] || {
    fail "仓库缺少 skills 源目录：$SOURCE_ROOT"
    return 1
  }
  mkdir -p "${layer_roots[@]}"

  while IFS= read -r -d '' skill_file; do
    skill_dir="${skill_file%/SKILL.md}"
    skill_name="${skill_dir##*/}"
    expected_skills["$skill_name"]=1
    sync_one_link "$SHARED_ROOT/$skill_name" "$skill_dir"
```
