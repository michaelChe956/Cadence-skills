# 历史产物清理与归档 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 删除 17 份无价值旧文档，将 45 份历史产物归档到 `cadence/archive/`，并完成 OpenSpec change `improve-progressive-disclosure-routing` 的标准归档。

**Architecture:** 一次性文件迁移：先扫描引用基线，再删除、再按原分类镜像归档并生成 INDEX.md，最后用 openspec CLI 归档已完成 change，复扫引用并输出核对清单。全程 `git rm`/`git mv` 保留历史。

**Tech Stack:** bash、git、openspec CLI（已确认可用：`/home/michaelche/.local/share/fnm/aliases/default/bin/openspec`）。

**OpenSpec 追溯:** Change = `archive-historical-docs`；本 Plan 只展开其工作包 1–5，不重新定义范围与验收。

## Global Constraints

- 所有移动用 `git mv`，删除用 `git rm`，禁止普通 `mv`/`rm`。
- 文件名保持不变，归档目录为 `cadence/archive/<原分类>/`。
- 不得修改 `.claude/rules/` 框架规则文件；其中若存在活引用，只报告不修改。
- 扫描与 grep 一律排除 `.git/`、`.worktrees/`。
- 本 Plan 文件自身（`cadence/plans/2026-07-20_计划文档_文档整理_历史产物清理与归档_v1.0.md`）是活跃 Plan，MUST NOT 被归档或删除。
- 预期核对数：删除 18、归档 45（plans 26、designs 13、analysis-docs 4、designs-reviews 1、prds 1）、specs 落地 3。

- [ ] **Step 2: 逐名扫描引用形成基线**

```bash
cd /home/michaelche/workspace/github/Cadence-skills
: > /tmp/doc-cleanup-baseline.txt

  grep -rl --exclude-dir=.git --exclude-dir=.worktrees --exclude-dir=node_modules -F "$name" . 2>/dev/null \

wc -l /tmp/doc-cleanup-baseline.txt
cat /tmp/doc-cleanup-baseline.txt
```

Expected: 输出全部引用对。`--exclude` 排除引用文件自身（路径含同名文件即被迁移文件本身）。人工阅读结果：区分「活引用」（`.claude/`、skills、`readmes/`、`AGENTS.md`、`CLAUDE.md`、`cadence/project-rules/` 中的引用，需修复）与「历史引用」（将被一并归档/删除的文档之间的互相引用，随迁移自然消失）。

: > /tmp/index-rows.txt

done
