# pre-check 执行脚本化实施 Plan

> **For agentic workers:** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按 Task 逐项实施；每一步使用 checkbox（`- [ ]`）跟踪，每个 Task 结束后运行独立测试。所有 commit 步骤均需维护者授权。

**Goal:** 将 pre-check 的 OpenSpec 四端投影、Superpowers Git 更新、四层软链同步和结构化复核收敛到一次 Bash 调用，在保持既有 `steps[]` 兼容的同时，以 `phases[]` 提供可断言结果，使任何场景（含首次安装与克隆）总耗时达到 2 分钟目标；240 秒仅作网络异常熔断。

**Architecture:** 保留 `pre-check.sh` 的六基础工具探测、参数和既有报告字段，在其上增加五阶段编排：`base-tools → openspec → superpowers-git → superpowers-links → verify`。模型层只定位绝对路径、在项目根调用一次 `run`/`check`、读取并呈现 JSON；脚本层完成所有确定性写入、候选源选择、所有权限定的软链处理、阶段计时和失败快返。测试以隔离 HOME、临时项目、fake CLI/Git 和 Python JSON 断言覆盖成功、幂等、失败关闭和分析文档列出的 10 条负向 fixture。

**Tech Stack:** Bash 3.2（macOS Bash，禁止 Bash 4.x 特性）、现有 `npx`/`uvx`/`ast-grep`/`codegraph`/`openspec`/`pi` CLI、Git、Python 3 标准库 `json`/`pathlib`/`unittest`，现有 `eval` stage1 流水线；不引入新依赖。

**Spec:** `cadence/designs/2026-09-04_design_pre-check执行脚本化_v1.0.md`

## Global Constraints

- **Bash 3.2 兼容：** 不使用关联数组、`mapfile`/`readarray`、`sort -V`、`grep -P`、GNU-only `readlink -f` 或 Bash 4.x 特性；候选使用普通 Bash indexed array，计数器在同一 Bash 进程内累积。
- **接口不扩展：** 只支持 `pre-check.sh run [--mirror <name>] [--no-interrupt] [--upgrade]` 与 `pre-check.sh check [--mirror <name>] [--no-interrupt]`；不增加 `--project-root` 或报告参数，项目根固定为调用 cwd 的 `pwd -P`。
- **产物 1:1：** 兼容性验收使用同一隔离 fixture 的旧实现基线与新实现快照逐项 diff；对目标写入按四端 OpenSpec 投影、Superpowers Git 与软链契约核对，zero-change 断言只要求非目标文件零改动，不能把四端投影白名单纳入“零改动”比较。脚本不得写 skill 目录、全局 npm/uv/git 配置、memory 或 API Key。
- **幂等与 `skipped` 语义：** `skipped` 统一表示该 phase 本次零写入，即 `created=0`、`updated=0` 且 `conflicts=0`；首跑有确定性写入时按实际结果记 `success`，二跑及已就绪只读 phase 记 `skipped`。OpenSpec 四端齐全时不执行 `update`；Superpowers Git 仍执行 `fetch` 与 `pull --ff-only`，但无新 revision 或 `Already up to date` 时 action 仍记 `fetch-pull-ff-only`、result 记 `skipped`。`verify` 为只读 phase，零写入且无冲突时记 `skipped`、action 为 `all-skipped`。
- **报告契约：** stdout 只能输出一份合法 JSON；stderr 才能输出中文摘要。原 `steps[]` 每项的 `name/status/action/version/error` 字段保持不动；新增 `phases[]` 每项至少含 `phase/result/action/duration_ms/created/updated/skipped/conflicts/error`，其中 `error` 为 `string|null`；Superpowers Git phase 另含 `origin/branch/before_revision/after_revision`，并在 `GIT_ERROR` 出口落 `error`；Verify phase 在 `VERIFY_ERROR` 出口落 `error`；顶层 `overall` 纳入五阶段，`hints` 保留。
- **中文：** 用户可见提示、错误、恢复建议、SKILL.md 新文案和测试失败信息均使用中文；函数名、字段名、命令和路径按现有英文契约保留。
- **Markdown 代码块：** 含有内层 Bash/Python 代码的文档代码示例使用四反引号外层、三反引号内层。
- **Playwright 与密钥边界：** 未明确要求 Playwright 时不安装、不写入；保留显式 opt-in。API Key 只展示 `your_zhipu_api_key`/`your_minimax_api_key` 占位符和安全提醒，不询问、不收集、不验证真实密钥。
- **失败快返与普通模式：** `--no-interrupt` 任一 phase 失败立即非零退出、下游 phase 不写入，并在已执行 phase 后把阻塞状态写入报告；普通模式由 `run_required_phase` 将失败 phase 记为 `partial` 后继续下游（不静默回退模型自由编排），最终由主流程统一 `emit_report`；`handle_failure` 只负责记录失败 phase、错误和返回码，不在 phase 内提前输出或退出。
- **网络预算：** Superpowers 单候选 60 秒、整个 `superpowers-git` phase 180 秒；phase 内每次 `clone`/`fetch`/`pull` 都把“单次上限”和 phase 剩余秒数取小值传给 `run_with_timeout`，phase 预算耗尽返回 124；超时按结构化 `failed`/`partial` 记录候选、错误和清理状态。
- **报告生命周期：** `<REPORT>` 由调用方在 `/tmp` 用 `mktemp` 创建并用 shell `trap` 清理；成功、失败、超时三条路径均不能残留独占报告。
- **范围：** 不修改 mcp-configuration、rule-config、project-rules-examples 的实现；仅按 T7 联动修改现有 eval 断言、runner、fixture 和 timeout 配置。
- **提交：** `cadence` 产物自动提交=关闭；每个 Task 的 commit 步骤标注“需维护者授权”，未获授权不得执行 `git commit`。

````python
class TestPhaseReport(unittest.TestCase):
    def test_check_has_five_timed_phases_and_legacy_steps(self):
        with tempfile.TemporaryDirectory() as td:
            project = Path(td) / "project"; project.mkdir()
            report = Path(td) / "report.json"
            env = os.environ.copy()
            env["HOME"] = str(Path(td) / "home")
            env["PATH"] = str(Path(__file__).parent / "helpers/fake-bin") + os.pathsep + env["PATH"]

                    ["bash", str(SCRIPT), "check", "--mirror", "default"],
                    cwd=project, env=env, stdout=fh, stderr=subprocess.PIPE, text=True)
            self.assertIn(proc.returncode, (0, 1))
            doc = json.loads(report.read_text(encoding="utf-8"))
            self.assertEqual(
                [p["phase"] for p in doc["phases"]],
                ["base-tools", "openspec", "superpowers-git", "superpowers-links", "verify"],
````

- [ ] **Step 3：实现最小五阶段骨架和计时**

将六个基础调用封装为 `do_base_tools`，并在 `emit_report` 前增加字符串累积；不使用关联数组。`phase_finish` 必须额外序列化 `error`（无错误为 `null`）；`run_phase` 默认只在 phase 零写入且无冲突时使用 `skipped`，不能无条件把返回码为 0 的 phase 记为 `success`；phase_finish 的 `error` 无错误时必须为 `null`。若 phase 发生写入则记 `success`，若普通模式部分完成则记 `partial`。

````bash
```bash
PROJECT_ROOT="$(pwd -P)"
PHASES_JSON=""
PHASE_CURRENT_STARTED_S=0
PHASE_CURRENT_CREATED=0; PHASE_CURRENT_UPDATED=0
PHASE_CURRENT_SKIPPED=0; PHASE_CURRENT_CONFLICTS=0
now_s() { date +%s; }
phase_begin() {
  PHASE_CURRENT_STARTED_S="$(now_s)"
  PHASE_CURRENT_CREATED=0; PHASE_CURRENT_UPDATED=0
  PHASE_CURRENT_SKIPPED=0; PHASE_CURRENT_CONFLICTS=0
}
phase_finish() {
  _error="${9:-null}"
  _item="{\"phase\":\"$(json_escape \"$1\")\",\"result\":\"$(json_escape \"$2\")\",\"action\":\"$(json_escape \"$3\")\",\"duration_ms\":$4,\"created\":$5,\"updated\":$6,\"skipped\":$7,\"conflicts\":$8,\"error\":$_error}"
  if [ -z "$PHASES_JSON" ]; then PHASES_JSON="$_item"; else PHASES_JSON="$PHASES_JSON,$_item"; fi
}
run_phase() {
  _phase="$1"; _function="$2"; phase_begin; PHASE_CURRENT_RESULT=""; PHASE_CURRENT_ERROR=""
  "$_function"; _rc=$?
  _elapsed=$((($(now_s) - PHASE_CURRENT_STARTED_S) * 1000))
  if [ "$PHASE_CURRENT_CREATED" -eq 0 ] && [ "$PHASE_CURRENT_UPDATED" -eq 0 ] && [ "$PHASE_CURRENT_CONFLICTS" -eq 0 ]; then
    _default_result=skipped
  else
    _default_result=success
  fi
  if [ "$_rc" -eq 0 ]; then
    _result="${PHASE_CURRENT_RESULT:-$_default_result}"
  else
    _result=failed
  fi
  _error_json=null
  [ -n "${PHASE_CURRENT_ERROR:-}" ] && _error_json="\"$(json_escape "$PHASE_CURRENT_ERROR")\""
  phase_finish "$_phase" "$_result" "${PHASE_CURRENT_ACTION:-$_function}" "$_elapsed" "$PHASE_CURRENT_CREATED" "$PHASE_CURRENT_UPDATED" "$PHASE_CURRENT_SKIPPED" "$PHASE_CURRENT_CONFLICTS" "$_error_json"
  return "$_rc"
}
do_base_tools() {
  _rc=0
  do_npx || _rc=1
  do_uvx || _rc=1
  do_ast_grep || _rc=1
  do_codegraph || _rc=1
  do_openspec || _rc=1
  do_pi_mcp_adapter || _rc=1
  return "$_rc"
}
```
````

`do_base_tools` 使用聚合返回值：先设 `_rc=0`，依次调用六个 `do_*`；任一失败仅将 `_rc` 置为 1，全部调用结束后 `return $_rc`。这样普通模式可由 `handle_failure` 记录错误，`--no-interrupt` 模式则在 base-tools 失败时立即标记 phase failed 并阻断下游写入。

````bash
parse_git_candidates() {
  GIT_CANDIDATES_COUNT=0; _raw="$CADENCE_SUPERPOWERS_GIT"

    case "$_raw" in *' '*) _candidate="${_raw%% *}"; _raw="${_raw#* }";; *) _candidate="$_raw"; _raw="";; esac
````

- [ ] **Step 3：实现 fetch/pull、浅克隆、timeout 和 revision 字段**

使用 `git -C`，临时 clone 目录成功后再移动；`run_with_timeout` 优先 `timeout`，否则使用后台 PID watchdog，超时返回 124。每次调用前按 phase 起始时间计算剩余秒数，并将 `min(60, phase_remaining_s)`（clone）或 `min(180, phase_remaining_s)`（fetch/pull）传给 `run_with_timeout`；phase 剩余时间不足 1 秒时不得再启动网络命令。关键调用必须是独立 argv：

````bash
```bash
run_with_timeout() {
  _limit="$1"; shift
  if command -v timeout >/dev/null 2>&1; then timeout "$_limit" "$@"; return $?; fi
  "$@" & _pid=$!; _elapsed=0
  while kill -0 "$_pid" 2>/dev/null; do
    [ "$_elapsed" -ge "$_limit" ] && { kill "$_pid" 2>/dev/null; wait "$_pid" 2>/dev/null; return 124; }
    sleep 1; _elapsed=$((_elapsed + 1))
  done
  wait "$_pid"
}
phase_remaining_s() {
  _now="$(now_s)"; _used=$((_now - PHASE_CURRENT_STARTED_S)); _remaining=$((180 - _used))
  [ "$_remaining" -gt 0 ] && printf '%s' "$_remaining" || printf '0'
}
git_timeout_for() {
  _single="$1"; _remaining="$(phase_remaining_s)"
  [ "$_remaining" -lt "$_single" ] && printf '%s' "$_remaining" || printf '%s' "$_single"
}
clone_superpowers() {
  _tmp="$(mktemp -d "${TMPDIR:-/tmp}/cadence-superpowers.XXXXXX")" || return 1
  _index=0; _selected=""; _errors=""
  while [ "$_index" -lt "$GIT_CANDIDATES_COUNT" ]; do
    _candidate="$(git_candidate_at "$_index")"; rm -rf "$_tmp/repo"; _timeout="$(git_timeout_for 60)"
    [ "$_timeout" -gt 0 ] || break
    if run_with_timeout "$_timeout" git clone --depth 1 "$_candidate" "$_tmp/repo" >/dev/null 2>"$_tmp/error"; then _selected="$_candidate"; break; fi
    _errors="$_errors$_candidate: $(cat "$_tmp/error" 2>/dev/null)\n"; _index=$((_index + 1))
  done
  [ -n "$_selected" ] || { rm -rf "$_tmp"; GIT_ERROR="clone-failed:$_errors"; return 1; }
  mv "$_tmp/repo" "$SUPERPOWERS_DIR" || { rm -rf "$_tmp"; return 1; }; rm -rf "$_tmp"
  GIT_ACTION=clone; GIT_ORIGIN="$_selected"; GIT_BRANCH="$(git -C "$SUPERPOWERS_DIR" rev-parse --abbrev-ref HEAD)"; GIT_BEFORE_REVISION=""; GIT_AFTER_REVISION="$(git -C "$SUPERPOWERS_DIR" rev-parse HEAD)"; PHASE_CURRENT_CREATED=$((PHASE_CURRENT_CREATED + 1))
}
update_superpowers() {
  validate_superpowers_repo || { GIT_ERROR=not-git; return 1; }
  GIT_BEFORE_REVISION="$(git -C "$SUPERPOWERS_DIR" rev-parse HEAD)"; GIT_BRANCH="$(git -C "$SUPERPOWERS_DIR" rev-parse --abbrev-ref HEAD)"; GIT_ORIGIN="$(git -C "$SUPERPOWERS_DIR" remote get-url origin 2>/dev/null)"
  _matched=0; _index=0
  while [ "$_index" -lt "$GIT_CANDIDATES_COUNT" ]; do _candidate="$(git_candidate_at "$_index")"; [ "$GIT_ORIGIN" = "$_candidate" ] && _matched=1 && break; _index=$((_index + 1)); done
  _timeout="$(git_timeout_for 180)"; [ "$_timeout" -gt 0 ] || { GIT_ERROR=phase-timeout; return 1; }
  if [ "$_matched" -eq 1 ]; then run_with_timeout "$_timeout" git -C "$SUPERPOWERS_DIR" fetch origin || return 1; else _selected=""; _index=0; while [ "$_index" -lt "$GIT_CANDIDATES_COUNT" ]; do _candidate="$(git_candidate_at "$_index")"; _timeout="$(git_timeout_for 60)"; [ "$_timeout" -gt 0 ] || break; run_with_timeout "$_timeout" git -C "$SUPERPOWERS_DIR" fetch "$_candidate" && { _selected="$_candidate"; break; }; _index=$((_index + 1)); done; [ -n "$_selected" ] || return 1; git -C "$SUPERPOWERS_DIR" remote set-url origin "$_selected" || return 1; GIT_ORIGIN="$_selected"; fi
  _timeout="$(git_timeout_for 180)"; [ "$_timeout" -gt 0 ] || { GIT_ERROR=phase-timeout; return 1; }
  run_with_timeout "$_timeout" git -C "$SUPERPOWERS_DIR" pull --ff-only origin "$GIT_BRANCH" || return 1
  GIT_AFTER_REVISION="$(git -C "$SUPERPOWERS_DIR" rev-parse HEAD)"; GIT_ACTION=fetch-pull-ff-only
  [ "$GIT_BEFORE_REVISION" = "$GIT_AFTER_REVISION" ] && PHASE_CURRENT_RESULT=skipped || PHASE_CURRENT_UPDATED=1
}
````

````bash
#!/usr/bin/env bash
set -u
TEST_DIR="$(CDPATH= cd -- "$(dirname -- "$0")" && pwd)"
SCRIPT="$TEST_DIR/../scripts/pre-check.sh"

snapshot() {
  _out="$1"; : > "$_out"
  (cd "$PROJECT" && find . -type f -not -path './.git/*' | sort) | while IFS= read -r _p; do
    printf 'file project %s %s\n' "$_p" "$(sha256sum "$PROJECT/$_p" | awk '{print $1}')" >> "$_out"

  (cd "$HOME_DIR" && find . -type f -not -path './.git/*' -not -path './.agents/superpowers/.git/*' | sort) | while IFS= read -r _p; do

for _layer in "$HOME_DIR/.agents/skills" "$HOME_DIR/.codex/skills/skills" "$HOME_DIR/.claude/skills" "$HOME_DIR/.pi/agent/skills"; do
      [ -d "$_layer" ] || continue
      for _link in "$_layer"/*; do
        [ -L "$_link" ] || continue
        _raw="$(readlink "$_link")"
        case "$_raw" in /*) _resolved="$_raw";; *) _resolved="$(cd "$(dirname "$_link")" && pwd -P)/$_raw";; esac
        printf 'link %s %s readlink=%s resolved=%s\n' "$_layer" "${_link##*/}" "$_raw" "$_resolved" >> "$_out"
      done
    done
  if [ -d "$HOME_DIR/.agents/superpowers/.git" ]; then
    printf 'git origin %s\n' "$(git -C "$HOME_DIR/.agents/superpowers" remote get-url origin)" >> "$_out"
    printf 'git branch %s\n' "$(git -C "$HOME_DIR/.agents/superpowers" branch --show-current)" >> "$_out"
````
