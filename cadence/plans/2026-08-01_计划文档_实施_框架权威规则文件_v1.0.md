# 框架权威规则文件 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `rule-config` 对 `.claude/rules/` 框架受管规则文件的处理从章节级保守合并改为框架权威全覆盖，统一备份为 `cadence/legacy/` 复制归档 + 原子覆盖，修复 code-usage 引用断链、摘要重复、技术栈占位卡死，并保证重复执行幂等。

**Architecture:** 资产三分法--框架受管规则文件走"内容==模板则跳过，否则（全局屏障已归档）atomic_write 模板"；L1 `openspec-superpowers-workflow.md` 保持版本化特例；L0 入口与 `openspec/config.yaml` 保留原语义。备份统一为 `backup_file` 复制到 `cadence/legacy/<时间戳[-N]>/<相对路径>`，原位由 `atomic_write` 原子替换。摘要判缺失改为"引用存在性 + 去重"，技术栈改为"逐项占位替换 + 差异入 report"。

**Tech Stack:** Python 3（`rule-config.py`，~3570 行）、pytest（`test_rule_config.py`，~2066 行，unittest 风格）、PyYAML、OpenSpec spec-driven schema。

## Global Constraints

- 落地名恒定为 `code-usage.md`（不使用带项目类型后缀的落地名）；L0 规范源 `agent-routing-kernel.md` 与 `RULE2_TEXT_*` 对 `code-usage.md` 的引用必须保持有效。
- `cadence/legacy/.gitignore` 内容固定为 `*\n!.gitignore\n`（忽略全部条目但保留自身）；每次归档前 `backup_file` 内部调用 `_ensure_legacy_gitignore` 验证/修复。
- 同秒冲突后缀加在时间戳**目录**后：`<时间戳>-2/<相对路径>`。
- 框架权威全覆盖资产集合固定 7 个：`mcp-servers.md`、`code-reading.md`、`document-storage.md`、`language.md`、`markdown-format.md`、`code-usage.md`、`playwright.md`。`playwright.md` 在"启用 Playwright"或"目标已存在"时进入处理清单；已存在时 drift 走全覆盖（不再 skip）。
- 不纳入全覆盖：L1 `openspec-superpowers-workflow.md`（版本化特例）、`agent-routing-kernel.md`（仅 L0 插入源，不复制到 `.claude/rules/`）、项目自定义规则、`cadence/project-rules/`。
- 历史框架产物迁移仅限精确文件名 `code-usage-coding.md`、`code-usage-noncoding.md`，不得触碰其他 `code-usage-*`。
- 技术栈占位集合固定 `{"待确认", "未检测到", ""}`（空值视为占位）；非占位真实值保留不覆盖，与检测值不同时入 report 提示。
- 备份语义为**复制**（`shutil.copy2`，原位不动）+ `atomic_write` 原子替换；**不使用 `shutil.move`**（atomic_write 失败原文件因 `os.replace` 原子性不变，无需回滚）。
- **全局备份屏障（`run_apply`）是受管文件归档的唯一入口**：S3/L0/L1/OS 的 drift/replace 资产由屏障统一归档；各 step 执行分支只做 `atomic_write`，不二次 `backup_file`。唯一例外：S3 历史遗留 `code-usage-*.md` 迁移是屏障外的独立归档（这些文件不在 `backup_needs` 清单）。
- 重复执行幂等：内容==目标态则跳过且不产生归档；执行 N 次 = 执行 1 次。
- `pre-check` skill 本次不改动。

def _ensure_legacy_gitignore(legacy_dir: Path) -> None:
    """确保 cadence/legacy/.gitignore 为 * + !.gitignore；缺失/损坏则修复。"""
    gi = legacy_dir / ".gitignore"
    expected = "*\n!.gitignore\n"
    if not gi.exists() or gi.read_text(encoding="utf-8") != expected:
        legacy_dir.mkdir(parents=True, exist_ok=True)
        atomic_write(gi, expected)


def backup_file(path: Path, root: Path) -> Path:
    """复制原文件到 cadence/legacy/<时间戳[-N]>/<相对 root 路径>。

    原位文件不动；归档复制失败抛 BackupError。同秒冲突在时间戳目录后追加 -2/-3。
    每次归档前验证/修复 .gitignore。
    """
    legacy_root = root / "cadence" / "legacy"
    _ensure_legacy_gitignore(legacy_root)
    stamp = datetime.now().strftime("%Y%m%d%H%M%S")
    rel = path.relative_to(root)
    dest_dir = legacy_root / stamp / rel.parent
    seq = 2
    while dest_dir.exists():
        dest_dir = legacy_root / f"{stamp}-{seq}" / rel.parent
        seq += 1
    dest_dir.mkdir(parents=True, exist_ok=True)
    backup_path = dest_dir / path.name
    try:
        shutil.copy2(path, backup_path)
    except OSError as exc:
        raise BackupError(f"归档失败：{path} -> {backup_path}（{exc}）") from exc
    return backup_path
```

def _ensure_summary_lines(text: str, entry_name: str, project_type: str = "non-coding") -> str:
    """确保 ## 强制规则 章节含各规则文件引用（按文件名存在性判缺失）；同文件多引用去重。"""
    rule2_text = RULE2_TEXT_CODING if project_type == "coding" else RULE2_TEXT_NONCODING
    rule6_block = RULE6_BLOCK_CLAUDE if entry_name == "CLAUDE.md" else RULE6_BLOCK_AGENTS
    # (规则文件名, 期望行); 规则6 用首行 marker
    rule6_first_line = rule6_block.splitlines()[0]  # 如 "### 6. 项目个性化规则..."
    required = [
        ("language.md", "- **必须使用中文回答** -> 详见 `.claude/rules/language.md`"),
        ("code-usage.md", rule2_text),
        ("document-storage.md", "- **Cadence 产物文档必须存放在 `cadence` 目录下；Claude Code 框架规则保留在 `.claude/rules/` 目录下** -> 详见 `.claude/rules/document-storage.md`"),
        ("markdown-format.md", "- **代码块嵌套使用 4 反引号/3 反引号** -> 详见 `.claude/rules/markdown-format.md`"),
        ("mcp-servers.md", ("- **各 MCP 工具的使用规范** -> 详见 `.claude/rules/mcp-servers.md`"
                            if entry_name == "CLAUDE.md"
                            else "- **各 MCP 工具及相关自动化工具的使用必须遵循项目规范** -> 详见 `.claude/rules/mcp-servers.md`")),
        ("code-reading.md", "- **大范围检索使用 CodeGraph，精确结构阅读优先使用 ast-grep outline** -> 详见 `.claude/rules/code-reading.md`"),
    ]
    lines = text.splitlines()
    rules_idx = next((i for i, l in enumerate(lines) if l.strip() == "## 强制规则"), None)
    if rules_idx is None:
        return text
    end_idx = len(lines)
    for idx in range(rules_idx + 1, len(lines)):
        s = lines[idx].strip()
        if s.startswith("## ") or s.startswith("# "):
            end_idx = idx; break
    section = lines[rules_idx:end_idx]
    section_text = "\n".join(section)
    # 去重：同一规则文件名只保留首个引用行，删除后续
    seen_refs = set()
    deduped = []
    for line in section:
        refs = [m for m in ["language.md","code-usage.md","document-storage.md","markdown-format.md",
                            "mcp-servers.md","code-reading.md"] if m in line]
        if refs:
            key = refs[0]
            if key in seen_refs:
                continue  # 重复引用，跳过
            seen_refs.add(key)
        deduped.append(line)
    # 补缺失
    missing = [line for marker, line in required if marker not in section_text]
    rule6_missing = rule6_first_line not in section_text
    if not missing and not rule6_missing:
        if deduped == section:
            return text  # 无变化
        return "\n".join(lines[:rules_idx] + deduped + lines[end_idx:])
    insert = list(missing)
    if rule6_missing:
        insert.extend(rule6_block.split("\n"))
    return "\n".join(lines[:rules_idx] + deduped + insert + lines[end_idx:])
```

def _ensure_techstack_block(text: str, tech_stack: dict) -> tuple:
    """逐项处理技术栈：占位替换为检测值，非占位真实值保留（差异入 diffs）。
    返回 (处理后文本, 差异列表[{"field","user_value","detected_value"}])。"""
    diffs = []
    if not tech_stack:
        return text, diffs
    fields = [("语言","language"),("包管理器","pkg_manager"),("测试命令","test"),
              ("检查命令","lint"),("格式化命令","format")]
    if "### 项目技术栈" not in text:
        lines = [f"- **{label}**：{tech_stack.get(key,'未检测到')}" for label,key in fields]
        block = "\n## 项目配置\n\n> 以下内容由初始化脚本根据项目环境自动检测生成，非通用规则。\n\n### 项目技术栈\n" + "\n".join(lines) + "\n- **覆盖率阈值**：80%\n"
        return text.rstrip("\n") + "\n" + block, diffs
    for label, key in fields:
        detected = tech_stack.get(key, "未检测到")
        pattern = f"- **{label}**："
        for line in text.splitlines():
            if line.startswith(pattern):
                current = line[len(pattern):]
                if current in PLACEHOLDER_VALUES:
                    text = text.replace(line, f"{pattern}{detected}", 1)
                elif current != detected:
                    diffs.append({"field": label, "user_value": current, "detected_value": detected})
                break
    return text, diffs
