# 方案设计：删除实体的矩阵与关系图表示（墓碑保留制）

- 日期：2026-09-21
- 版本：v1.0
- 状态：已按"最保守标准选项"裁决（墓碑保留制），随 OpenSpec 变更一并确认
- 来源：kb-eval 四端 P3 专项验证中 codex 端发现（`evals/kb/results/2026-09-21/codex-p3-verify/`）：update 删除实体后矩阵保留历史行但 ID 加注记后缀、图剔除节点，导致"图节点⊇矩阵两端"等值校验失败——update skill 的"保留删除证据、旧关系和历史"与矩阵/图契约之间规约空白

## 1. 规则（墓碑保留制）

1. **稳定 ID 不可变**：被删除实体的 ID 保持原样，禁止任何后缀/前缀注记（"（已删除）""（源实体已删除 日期）"均违规）。删除是状态，不是新标识符。
2. **矩阵**：涉及已删除实体的历史行原位保留；`关系类型` 不变；`证据状态` 使用新枚举值 **`已失效`**；`关系证据` 列可追加删除证据（如 `删除提交 <sha>`）；`详情链接` 指向承载删除证据的文档锚点。
3. **关系图**：被删除实体保留**墓碑节点**（原有 id/kind/label/doc 不变，`status: deleted`，可加 `deleted_evidence`）；指向/来自它的边保留（`evidence` 不变，可加 `invalid: true`）。图不因删除而丢节点或丢边。
4. **等值校验口径不变**：`图边数 == 矩阵全部数据行数（含已失效行）`、`图节点 ⊇ 矩阵两端（含墓碑）`——行/边/节点三者同保留，校验无需特例。
5. `已失效` 证据状态仅由 Update 删除流程产生；初始化阶段不得使用。
