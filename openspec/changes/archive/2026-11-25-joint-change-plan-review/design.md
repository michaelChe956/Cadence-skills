# 工作流设计的归属与迁移

## Context

`rule-config` 发布入口路由、完整协作规则和 OpenSpec 配置。旧配置在升级时保留了原有 context 中所有完整行。完整的任务设计、审查及用户确认见 [Design v1.0](../../../../cadence/designs/2026-11-25_方案设计_初始化项目工作流联合送审_v1.0.md)。

## Goals / Non-Goals

本仓定义阶段、产物、送审条件、人工确认、恢复和交付去向。`cadence-subagents-config` 定义选角、派工和复核方式。

## Decisions

- L0 v6 指向详细规则，L1 记录阶段与恢复决策。OpenSpec 的 context 和 artifact 规则把这些门禁带入原生指令。
- 复用任务产物或交接记录保存委托、用户决定和同版审查凭据。范围变化回 Design，联合包变化回联合编写。
- S4 按历史模板识别 L0，S3 优先用本地基线抽取用户差异，缺基线时识别旧 L1 正文。S7 在原有配置中按字段和完整条款迁移。

## Risks / Trade-offs

旧 L1 的多个正文共用 v1 标记。历史正文与用户新增必须分开识别。恢复入口的实际决策通过生成后的项目会话验证，配置升级通过真实 CLI 和文件快照验证。
