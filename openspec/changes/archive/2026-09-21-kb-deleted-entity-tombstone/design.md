# Design

墓碑保留制（已裁决，理由见 `cadence/designs/2026-09-21_方案设计_删除实体的矩阵与图表示_v1.0.md`）：

- 稳定 ID 不可变——删除是状态不是新标识符，codex 式注记后缀违规
- 行/边/节点三者同保留 → 等值校验零特例（弃"移除制"：矩阵分节+校验分口径+丢就地历史，三处复杂度换零收益）
- `已失效` 仅 Update 产生——防止初始化期滥用掩盖证据缺口

## 失败处理

| 失败 | 处理 |
|------|------|
| 更新后矩阵行 ID 带注记 | global-validation 第 5 项判 failed（ID 不在合法稳定 ID 集） |
| 图丢墓碑节点/失效边 | 第 6 项等值校验判 failed |
| 初始化写入已失效 | 第 5 项判 failed |

## 兼容性

新增枚举值纯扩展；存量库无 `已失效` 不受影响；等值校验算法不变。

## 权衡记录

| 备选 | 弃用原因 |
|------|---------|
| 移除制（矩阵删行进历史分区，图删节点） | 校验需分口径、历史不在原位、矩阵布局复杂化 |
| ID 注记（codex 自发方案） | 破坏稳定 ID 不可变与 ID 匹配 |
